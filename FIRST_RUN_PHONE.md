# Mini-Jarvis — First Run

## 1. Install
Use Termux on Android, extract this ZIP, then run:

```bash
cd mini-jarvis-phone-api
./setup.sh
```

## 2. Start
Run:

```bash
./run.sh
```

On the first run, Mini-Jarvis will ask for your **OpenAI API key locally** and create `.env`.

You do **not** need to put the key into the ZIP or send it to anyone.

## 3. Open
On the same phone:

`http://127.0.0.1:8000`

API documentation:

`http://127.0.0.1:8000/docs`

## Security
Keep `.env` private. Do not upload it or share its contents.
